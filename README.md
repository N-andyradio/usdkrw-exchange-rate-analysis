# 원/달러 환율 5년 반 들여다보기

원/달러 환율이 2021년 1월부터 2026년 9월까지 어떻게 움직였는지, 그리고 하루 만에 크게 출렁인 날에는 무슨 일이 있었는지 데이터로 살펴본 프로젝트입니다.

자세한 분석 과정과 인사이트는 [REPORT.md](REPORT.md)에 정리했습니다.

## 한눈에 보기

- 환율은 2021년 초 약 1,085원에서 2026년 6월 최고점(1,554.48원)까지 약 43% 올랐습니다. 올라가기만 한 건 아니고, 고점을 찍은 뒤 크게 내려오는 구간이 여러 번 있었습니다.
- 평소 하루 변동 폭은 0.6% 안팎인데, 큰 사건이 있을 때는 이 폭이 평소의 두 배 넘게 커졌습니다.
- 하루 변동이 유난히 컸던 날은 4일이었고, 모두 급락이었습니다. 네 날 모두 같은 시기의 뉴스와 연결됐습니다.
- 월별·요일별로 환율이 일정하게 움직이는 뚜렷한 패턴은 찾지 못했습니다.

## 이상치 4일 이야기

일별 변화율이 평소 범위(IQR의 3배 기준, -2.49% ~ +2.55%)를 벗어난 날이 4일 있었습니다. 이 날들이 데이터 오류인지, 실제로 환율이 움직인 건지 먼저 확인했습니다. 전후 일주일의 값을 보니 하루만 튀었다가 돌아오는 모양이 아니라 변동이 이어졌고, 날짜별로 뉴스도 찾아봤습니다.

**2022-11-14 (-2.69%)**
미국 10월 소비자물가가 예상보다 낮게 나오면서 "연준이 금리를 예전만큼 올리지 않겠구나" 하는 기대가 커졌고, 달러가 약해졌습니다. 서울 시장에서는 이 충격이 11월 11일 하루에 59.1원 하락으로 나타났는데, 제 데이터에서는 같은 하락이 11-11과 11-14 두 날에 나뉘어 기록되어 있었습니다. 그래서 11-14의 하락은 이 소비자물가 충격의 뒷부분으로 봤습니다.

**2022-12-01 (-3.44%)**
파월 연준 의장이 빠르면 12월부터 금리 인상 속도를 늦추는 게 합리적이라고 말했고, 같은 시기 미국 민간 고용도 예상보다 약하게 나왔습니다. 달러가 약해지면서 환율이 장 초반에 1,300원 아래로 내려갔습니다.

**2025-04-10 (-2.84%)**
트럼프 대통령이 중국을 뺀 나머지 나라의 상호관세를 90일 동안 미루겠다고 발표했습니다. 뉴욕증시가 급등하고 위험을 감수하려는 분위기가 돌아오면서 원화가 강해졌습니다.

**2025-05-05 (-2.52%)**
이날은 서울 외환시장이 쉬는 날(연휴 5월 3~6일)이라, 이 값은 해외(역외) 시장에서 거래된 가격입니다. 연휴 동안 대만 달러와 위안화 같은 아시아 통화가 크게 오르면서 원화도 같이 움직였습니다.

네 날 모두 오류로 보기 어려웠고, 실제 사건과 이어져 있어서 지우지 않고 그대로 분석에 썼습니다. 다만 뉴스는 같은 시기에 있었던 사건일 뿐이고, 그것이 환율 변동의 원인이라고 증명한 건 아닙니다.

## 분석하면서 알게 된 점

- 같은 환율 데이터라도 출처에 따라 날짜 기준이 다를 수 있습니다. 서울 종가와 Yahoo Finance 값을 맞춰 보니, 하루에 몰린 급락이 두 날짜로 나뉘어 기록된 경우가 있었습니다. 그래서 요일별 분석은 이 영향을 받았을 수 있습니다.
- 서울 시장이 쉬는 날의 값은 해외 거래 가격이라서, 평일 값과 성격이 조금 다릅니다.
- 2026년 하반기에 환율이 크게 내려온 이유는 확인하지 못했습니다.

## 실행 방법

Python 3.13에서 실행을 확인했습니다. Python 3.15에서는 일부 패키지 설치가 실패했습니다.

1. 저장소를 내려받습니다.

```
git clone https://github.com/N-andyradio/usdkrw-exchange-rate-analysis.git
cd usdkrw-exchange-rate-analysis
```

2. 가상환경을 만들고 켭니다.

```
python -m venv .venv

# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate
```

3. 패키지를 설치합니다.

```
pip install -r requirements.txt
```

4. (선택) 데이터를 새로 수집합니다. `data/` 폴더에 CSV가 이미 들어 있어서 건너뛰어도 됩니다.

```
python collect_data.py
```

5. `analysis.ipynb`를 VS Code나 Jupyter에서 열고 위에서부터 차례로 실행합니다. VS Code에서는 오른쪽 위 커널을 `.venv`로 선택합니다.
